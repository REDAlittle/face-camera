# Face caméra · Média training

Présentation web du média training du Club des Inspirées avec GoPod Studios.

- Présentation : `index.html` (plein écran : touche F)
- Page de vote pour les téléphones : `v/` (QR codes affichés dans la présentation)

## Commandes
→ / Espace / clic : suivant · ← : précédent · F : plein écran · P : vue présentatrice (notes, chrono, votes)
G : plan général · B : écran noir · T : remettre le chrono REC à zéro · 0 : relancer le minuteur de la page
D : tirer une carte question · H : masquer le viseur · N deux fois : nouvelle salle de vote · ? : aide
